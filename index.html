☁️ Salvataggio su GitHub

📜 Cronologia delle modifiche
Come si configura (circa 5 minuti)
  1. Su GitHub crea un repository privato (es. turni-dati) spuntando “Add a README file”.
  2. Vai su Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. In “Repository access” scegli Only select repositories e seleziona solo turni-dati.
  4. In “Permissions → Repository permissions” imposta Contents: Read and write. Scegli una scadenza (es. 1 anno) e genera.
  5. Copia il token, incollalo qui sopra insieme a utente e repository e premi Collega e sincronizza.
  6. Su ogni altro dispositivo apri la stessa pagina e inserisci gli stessi dati.

Ogni salvataggio diventa una “versione” su GitHub: dalla cronologia puoi recuperare qualsiasi stato precedente (scarica il file dati.json e importalo qui sotto). Se due dispositivi modificano insieme, l'app se ne accorge e ti chiede quale versione tenere invece di sovrascrivere.
